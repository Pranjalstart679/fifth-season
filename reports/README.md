# Evaluation Reports and Figures

This directory stores outputs generated by the `scripts/visualization/` and `scripts/modeling/evaluate.py` pipelines. 

## Structure
*   `figures/`: Contains rendered static visualizations (PDFs/PNGs) of our predicted Aerosol composition heatmaps vs the actual satellite imagery.
*   `metrics.csv` / `evaluation.txt`: Output results capturing multi-epoch structural similarity index (SSIM) values and mean squared errors (MSE).
